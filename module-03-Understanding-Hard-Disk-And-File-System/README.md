# CHFI Module 3 - Understanding Hard Disk and File System

---

## 📚 Module Overview

This module covers fundamental concepts related to hard disks and file systems, which are critical for forensic investigators to understand in order to perform accurate data recovery, analysis, and investigation.

---

## 🎯 Learning Objectives

- Understand the structure and components of hard disks.
- Learn different types of storage media and their characteristics.
- Explore the concept of partitions, volumes, and clusters.
- Understand various file systems (FAT, NTFS, EXT, etc.) and their structures.
- Comprehend how data is stored, organized, and retrieved on disk.
- Understand file system metadata and its importance in forensic analysis.
- Learn about common artifacts and how to analyze file systems during an investigation.

---

## 📝 Key Topics Covered

1. **Hard Disk Fundamentals**  
   - Physical structure of hard disks (platters, heads, tracks, sectors)  
   - Types of hard disks: HDD, SSD, Hybrid  
   - Disk interfaces and controllers (IDE, SATA, SCSI)  

2. **Storage Concepts**  
   - Logical vs physical storage  
   - Partitions, volumes, and logical drives  
   - Cluster and sector size  

3. **File System Basics**  
   - Purpose and role of a file system  
   - Types of file systems:  
     - FAT (FAT12, FAT16, FAT32)  
     - NTFS (New Technology File System)  
     - EXT (Linux file systems)  
     - Others (exFAT, HFS+)  

4. **File System Structures**  
   - Master Boot Record (MBR) and GUID Partition Table (GPT)  
   - File Allocation Table (FAT)  
   - Master File Table (MFT) in NTFS  
   - Inodes in EXT file systems  

5. **File System Metadata**  
   - Metadata components (timestamps, permissions, attributes)  
   - Importance of metadata in forensic analysis  

6. **Forensic Artifacts in File Systems**  
   - Deleted file recovery  
   - Hidden data and slack space  
   - Journaling and logs  

---

## 🛠️ Tools & Techniques

- Tools used to analyze file systems (e.g., FTK Imager, Autopsy, EnCase)  
- Techniques for disk imaging and cloning  
- Methods to recover deleted files and metadata extraction

## ⚠️ Important Notes

- Understanding file system structures is essential for accurate forensic investigations.  
- Always work on disk images or clones to avoid tampering with original evidence.  
- Knowledge of different file systems helps in multi-platform investigations.

---

## 📝 Summary

This module lays the foundation for forensic investigators by explaining how data is physically and logically stored on storage devices and how different file systems manage data. Mastery of these concepts is essential for conducting effective forensic examinations and recovering critical evidence.
